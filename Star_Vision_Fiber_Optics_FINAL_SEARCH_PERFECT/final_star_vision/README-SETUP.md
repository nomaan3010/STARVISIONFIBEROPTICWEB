# Star Vision Fiber Optics — Final Website

This is the final static Star Vision Fiber Optics enquiry website.

## Final router images
- ₹950 — 300Mbps Wireless N Router: front + back images
- ₹1,650 — Dual Band FTTH Router: front + exact supplied product-box image

The product cards and product-detail modal use an Amazon-style image gallery with thumbnails.

## Run
Open `index.html` in a browser, or upload the entire folder to your static hosting provider.

The website is an enquiry storefront. Cart enquiries are sent to WhatsApp; it does not process online card/UPI payments or store orders on a server.
